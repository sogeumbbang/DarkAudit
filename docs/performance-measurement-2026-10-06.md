# DarkAudit 실모델 성능 측정 — 2026-10-06

로컬 작업 트리의 실제 분석 모델 `gpt-6-luna`로 측정했다. 보험·예적금 합성 22 Flow(11쌍), 110화면을 이미지 분석과 규칙 후보+LLM 분석에서 각각 3회 평가했다. 데이터셋이 같은 반복 측정이며 66개의 독립 Flow를 평가한 것은 아니다.

Flow 안에 규칙이 존재하는지를 분류 단위로 사용했다. 전체 쌍 기준 Accuracy는 실패·보류도 전체 분모에 포함한다. 실패·미판정은 정상으로 세지 않으며 정답 양성은 미탐으로 반영한다. 위치 평가는 같은 규칙·화면 및 IoU 기준의 일대일 매칭이다. 규칙+LLM의 위치에는 DOM 후보 좌표가 포함되므로 이미지 분석의 위치 성능과 입력 조건이 다르다.

이미지 분석 실패 2건은 첫 회차 `ins-001-risky`, `ins-009-risky`의 화면 참조 불일치였다. 두 번의 모델 출력 생성 후에도 `related elements must reference evidence screens in where.screen_ids` 검증을 통과하지 못했다. 이후 회차에는 성공했으며 실패한 첫 결과도 집계에서 유지했다.

이 데이터에서는 모든 규칙을 미탐지로 답해도 Accuracy가 85.5%다(Recall 0%). 따라서 Accuracy만으로 품질을 판단하지 않는다. 규칙 후보를 모두 양성으로 처리한 동일 단위 기준선은 Precision 47.1%, Recall 100%, F1 64.0%였다.

## 챗봇 Ragas 평가

저장소 규칙에 근거해 작성한 개발용 질문 12개를 실제 챗봇에 입력했다. 답변·검색 청크 전문을 기록하고 Ragas 0.4.3으로 평가했다. 답변 모델과 평가 모델은 모두 `gpt-6-luna`이며 임베딩 모델은 `text-embedding-3-large`다. 같은 모델이 평가하므로 자기평가 편향이 있을 수 있다. 독립 전문가가 검수한 골드셋은 아니다.

| 지표 | 평균 | 유효 평가 수 |
| --- | ---: | ---: |
| faithfulness | 0.864 | 12/12 |
| response_relevancy | 0.671 | 12/12 |
| context_precision | 0.817 | 12/12 |
| context_recall | 0.917 | 12/12 |

평가 실패 사례: 0/12. Faithfulness는 제공된 검색 근거에 대한 충실성이며 외부 사실 정확도를 보장하지 않는다.

실패 분석: `emotion` 질문(“혜택을 포기하고 나가기”라는 거절 문구)에서 DA-12 관련 근거를 검색하지 못했다. 답변은 DA-12를 설명하면서 DA-02 관련 문서를 인용했다. 이 질문의 Context Precision/Recall은 모두 0, Faithfulness는 0.222였다. 검색 재현율과 인용 일치 검증을 우선 개선할 대상이다.

## 설명·개선안 평가

이미지 분석 첫 회차에서 실제 출력된 설명·개선안 58건을 모두 평가했다. 정상 Flow의 오탐 설명도 포함하며 누락된 탐지는 생성 문장이 없어 이 점수의 대상이 아니다. 화면 및 독립 DOM 관찰을 근거로 G-Eval에서 착안한 rubric judge를 사용했고 평가 모델은 `gpt-6-luna`다.

| 기준 | 평균(5점 만점) |
| --- | ---: |
| groundedness | 3.57 |
| rule_validity | 3.43 |
| actionability | 3.53 |

평가 완료 58/58건. 설명 점수를 탐지 정확도와 합쳐 해석하지 않는다.

평가자에게는 독립 DOM 수치를 추가 제공했다. 이미지 분석 모델이 “수치 자료가 없다”고 밝힌 문장을 평가자가 DOM 수치와 모순된다고 감점한 사례(`ins-005-clean-finding-3`)가 있다. 실제 근거 오류와 생성 모델이 받은 입력의 한계를 혼동할 수 있어, 이 평점은 사람의 검수가 필요한 개발용 신호다.

## 조건과 한계

- 지원 5종(DA-03/04/07/12/15)만 탐지 지표에 포함했다. 합성 화면의 원래 라벨은 생성기가 의도적으로 심은 패턴 기준이다. 미라벨 패턴이 오탐으로 집계될 가능성이 있다.
- 원본 라벨을 변경하지 않고 현재 렌더링에 맞는 별도 라벨을 생성했다. 7개 Flow에서 폰트·줄바꿈 등에 따른 좌표/요소 텍스트 차이가 있었으나 유형별 양성 라벨 수는 같다. 정상 11개 라벨은 원본과 동일하다.
- Tesseract 4.1.1, kor+eng, 이미지 780×1688 기본, Chromium 캡처를 사용했다. 탐지 추론 동시 실행 수는 4이며 일부 구간에는 RAG·설명 평가도 병행했다. 응답 시간에는 OCR·위치 보정 및 재시도가 포함된다.
- 별도로 검수된 전후 비교 상태 정답셋은 없어 해결·유지·재발 분류의 성능은 측정하지 않았다. 원본/정상 쌍 일관성은 측정했지만 해당 상태 평가를 대체하지 않는다.
- 달러 비용은 산출하지 않았다. 원본 보고서의 토큰 수는 성공한 분석에서 기록된 사용량이며 실패 호출의 누락이 있을 수 있다.
- 응답 시간은 저장된 입력을 분석하는 파이프라인 구간이다. 브라우저 캡처·업로드·HTTP 대기 시간은 포함하지 않으며 실제 서비스의 전체 응답 시간과 다르다. P95는 성공 표본의 nearest-rank 값이다.
