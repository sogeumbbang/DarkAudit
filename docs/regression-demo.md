# 원본·수정본 데모 재검증

현재 사용법은 [데모 v3 안내](../demo/README.md)를 따른다. 기존 문서의 특정 Audit ID와 모델 실험 응답은 과거 기록이며 현재 실행 결과가 아니다.

1. 새 진단 화면에서 보험·환전 멤버십·신용관리 구독 중 하나와 ‘문제 포함 원본’을 선택한다.
2. ‘스크린샷 데모 실행’ 또는 ‘URL 데모 실행’을 누른다.
3. 완료 화면이나 결과 화면에서 ‘데모 수정본 실행’을 연다.
4. ‘일부 수정본’을 실행하면 같은 Audit의 다음 회차가 생성된다.
5. ‘전체 개선본 선택’ 후 다시 실행하면 세 번째 회차가 생성된다.
6. ‘전후 비교 보기’에서 최신 완료 두 회차의 해결·유지·개선·신규·재발·보류를 확인한다.

일부 수정본은 기본 체크와 필수 비용 공개를 고치고, 전체 개선본은 위계·가독성·압박 문구 등을 추가로 고친다. 단계명과 화면 순서는 유지한다. 수정본부터 별도의 데모 진단을 시작할 수도 있다.

진단의 `demoPreset`에는 scenario와 source가 저장되고, 최근 회차의 `demoVariant`는 risky/partial/revised를 반환한다. 업로드 API의 `demo_variant` 및 URL 캡처 API의 `demoVariant`는 버전 표시에만 사용하며 모델의 정답 입력으로 사용하지 않는다.

실제 분석에는 기존 provider 설정이 적용된다. `fake`는 실제 검사 결과가 아니므로 해결률은 보류될 수 있다. 입력 6장의 배치 분할 경고, 근거 부족, 변경된 탐색 경로 등도 해결 판정을 막을 수 있다. 미탐지를 무조건 해결로 처리하지 않는다.

기존 식별 정보 없는 데모 진단은 이름만으로 추정해 수정하지 않는다. v3에서 새 데모를 실행하면 이후 새로고침과 재접속 후에도 수정본 실행 버튼이 유지된다.
