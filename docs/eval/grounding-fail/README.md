# grounding-fail — 텍스트형(DA-07·DA-12) 위치 실패 진단 이미지

스크린샷(LLM 단독) 경로에서 IoU 0.5에 못 미친 케이스를 원본 화면에 겹쳐 그린 것이다.

- **초록 박스**: 정답 라벨(합성 데이터 생성기가 HTML에서 추출한 요소 박스)
- **빨강 박스**: 모델이 낸 박스(진한 빨강 = 정답과 가장 가까운 예측, 연한 빨강 = 같은 화면의 다른 예측)
- **파랑 박스**(`*_after.png`): 근거 문장 OCR 매칭으로 보정한 박스 (`fix/text-grounding`)

파일명: `{flow}_s{화면}_{규칙}_run{회차}.png`. 분석은 `docs/eval-results.md` §16.
`dep-001-risky_s1/s2_DA-07`은 모델이 해당 화면의 문제를 아예 탐지하지 못한 케이스(박스 없음)다.
