# Fonts

Self-hosted, unmodified variable WOFF2 fonts. Downloaded 2026-09-28.

- Wanted Sans: https://github.com/wanteddev/wanted-sans
  - Source: `packages/wanted-sans/fonts/webfonts/variable/complete/woff2/WantedSansVariable.woff2`
  - License: `WantedSans-OFL.txt` (SIL Open Font License 1.1)
  - Used for headings, weights 400–1000.
- SUIT: https://github.com/sun-typeface/SUIT
  - Source: `fonts/variable/woff2/SUIT-Variable.woff2`
  - License: `SUIT-LICENSE.txt` (SIL Open Font License 1.1)
  - Used for body text and controls, weights 100–900.

Keep the license files with the fonts when redistributing.
